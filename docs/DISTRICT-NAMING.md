# District naming

Approved by the project owner on October 6, 2026.

Use **Shelby County, TN Emergency Communications District** as the formal organization name in page introductions, footer identification, and organization references. Retain the proper organization name in both languages.

This is a review-site content update. Dashboard, metrics, GIS, WordPress production, and DNS are outside this change.
